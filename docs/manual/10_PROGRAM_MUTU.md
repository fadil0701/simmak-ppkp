# Program Mutu

## 1. Kegunaan
Mengelola program mutu klinik, indikator kinerja, dan hasil pengukuran untuk tren mutu.

## 2. Route
`/quality` — permission: `quality.view` / `quality.manage`

## 3. Siapa yang Menggunakan
| Role | Akses |
|------|-------|
| super-admin, admin-mutu, pj-mutu | View + Manage |
| kepala-klinik, tim-akreditasi | View |
| Lainnya | Tidak |

## 4. Cara Pengisian & Penggunaan
1. Buka **Program Mutu**.
2. Lihat daftar program aktif dan indikator terkait.
3. Untuk pengelolaan (role manage):
   - Pastikan program terhubung klinik/periode yang benar.
   - Input pengukuran indikator secara berkala.
4. Hasil pengukuran tampil sebagai tren di **Dashboard Klinik**.

## 5. Hubungan Modul Lain
Indikator mutu mendukung kesiapan akreditasi dan pelaporan eksekutif.
