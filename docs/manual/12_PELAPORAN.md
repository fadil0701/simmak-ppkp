# Pelaporan

## 1. Kegunaan
Halaman ringkasan pelaporan eksekutif: tautan cepat ke export ranking klinik dan overview indikator utama.

## 2. Route
`/reports` — permission: `dashboard.executive`

## 3. Siapa yang Menggunakan
| Role | Akses |
|------|-------|
| super-admin, admin-mutu | Ya |
| Lainnya | Tidak |

## 4. Cara Menggunakan
1. Login sebagai admin/direktur.
2. Buka menu **Pelaporan**.
3. Tinjau ringkasan.
4. Gunakan tautan **Ekspor ranking klinik** bila perlu unduh CSV.
5. Untuk detail operasional, buka modul sumber (Audit, CAPA, Risiko, dll.).

## 5. Catatan
Export CSV ranking juga tersedia langsung di Dashboard Eksekutif (`/dashboard/export-ranking`).
